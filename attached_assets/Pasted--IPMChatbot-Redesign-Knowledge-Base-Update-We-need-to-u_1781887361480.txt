# IPMChatbot Redesign + Knowledge Base Update

We need to update the IPMChatbot Replit app, which powers the floating help/chat button on the IPM website.

Website reference:
https://www.ipm.services

Git/branch instructions:

* Start from the latest `main` branch.
* Create a new branch named: `ipm-chatbot-brand-refresh`
* Do not overwrite unrelated files.
* After changes, test locally, commit, and prepare for deploy.

## Main Goal

Redesign the floating chatbot widget so it matches the new IPM website theme, branding, colors, tone, and professional luxury property management style.

The chatbot should feel like a natural part of the new IPM website, not a separate blue generic chatbot.

## Visual Design Updates

Update the chatbot widget UI to match the new IPM website:

* Replace blue theme with IPM website colors.
* Use dark navy, white, cream/light neutral backgrounds, and gold accent colors.
* Update the chat header to look premium and branded.
* Use the IPM logo if available in the project assets.
* If logo is not available, add a clear placeholder path and comment where the new logo should be added.
* Floating button should use the new brand colors.
* Remove the generic blue styling.
* Make it look modern, clean, high-end, and trustworthy.
* Make sure the widget looks good on desktop and mobile.
* Keep the widget compact and not blocking too much of the page.
* Suggested question buttons should be fully readable and should wrap text properly.
* No black backgrounds unless it is the same dark navy used on the website.

Add clear knowledge explaining IPM’s 10%–20% property management tier structure.

Use this general structure:

### 10% Tier

Best for owners who only need basic support or partial management.

Can include:

* Listing support
* Reservation coordination
* Owner guidance
* Limited guest communication
* Basic reporting

### 15% Tier

Best for owners who want more active management and stronger support.

Can include:

* Guest messaging

* Listing optimization

* Maintenance coordination

### 20% Tier

Best for full-service property management.

## Lead Capture Rule After 3 Questions

After the visitor asks 3 questions in the chatbot, the chatbot should encourage them to contact IPM directly.

Add logic like:

“Looks like you may be interested in property management support. For the best next step, please contact our team so we can review your property and recommend the right management plan.”

Then show a clear call to action:

* Email: [info@ipm.services](mailto:info@ipm.services)
* Website: https://www.ipm.services/contact
* Button text: “Contact IPM”
* Optional button text: “Email Our Team”

The chatbot should still answer basic questions, but after the 3rd user question it should gently guide them toward contacting IPM.
